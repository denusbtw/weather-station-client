# Weather Station Client

Android-застосунок для лабораторних робіт №1–2. Барометр з лабораторної №1 показує тиск і погодний стан. У лабораторній №2 додано програмну імітацію BLE-хаба; фізичний Bluetooth для демонстрації не потрібен.

## Віртуальний BLE-профіль

| Елемент | UUID | Операція |
| --- | --- | --- |
| Weather Station Hub service | `7f0b1000-65e8-4b26-a9f0-9d6417a90201` | GATT-сервіс |
| Status characteristic | `7f0b1001-65e8-4b26-a9f0-9d6417a90201` | Read, Notify |
| Data characteristic | `7f0b1002-65e8-4b26-a9f0-9d6417a90201` | Write |

Протокол передачі: застосунок записує рядок `PRESSURE_HPA=1013.2` у Data characteristic. Після підключення хаб повертає `READY` через Read; після запису відповідає `RECEIVED` через Notify. Це події `MockBleConnector`, а не реальні GATT-виклики. Усі події з'являються в терміналі застосунку та в Logcat із тегом `MockBleConnector`.

## Перевірка в емуляторі

1. Запустити застосунок та натиснути **Пошук пристроїв**. Приблизно за 2 секунди з'явиться `Weather Station Hub`.
2. Натиснути **Підключитися**. Статус зміниться на `Connected`, у терміналі з'явиться `READ ... READY`.
3. Змінити тиск повзунком або віртуальним сенсором і натиснути **Надіслати поточний тиск**. У терміналі та Logcat з'являться `WRITE` і `NOTIFY ... RECEIVED`.
4. Натиснути **Відключитися** або згорнути застосунок. Статус зміниться на `Disconnected`.

Дозволи Bluetooth для Android 12+ та старіших версій задекларовано в `AndroidManifest.xml` відповідно до завдання. Mock-реалізація не звертається до Bluetooth API, тому не запитує ці дозволи під час роботи. Для справжнього BLE-клієнта треба буде додати перевірку й запит дозволів під час виконання.
